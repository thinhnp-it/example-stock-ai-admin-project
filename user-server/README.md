# Authentication service (`user-server`)

FastAPI service that authenticates one administrator configured at deployment and issues HS256 JWTs. Other backend services validate tokens locally using the same secret; they do not call this service for every request.

## Workflow and purpose

1. `POST /auth/login` accepts an email and password.
2. The service compares the normalized email and verifies a PBKDF2-SHA256 password hash.
3. On success it returns an eight-hour JWT and user profile.
4. `GET /auth/me` validates a bearer JWT and returns its profile.
5. `GET /healthz` is an unauthenticated liveness endpoint.

The administrator password is stored as a hash, not plaintext. Generate one interactively from this directory:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python hash_password.py
```

The helper prompts for a password (minimum 12 characters) and prints a `pbkdf2_sha256$...` value. Put that value in `AUTH_ADMIN_PASSWORD_HASH`; do not store the plaintext password in `.env`.

## Environment variables

Copy `.env.example` to `.env` and set:

| Variable | Required | Description |
| --- | --- | --- |
| `AUTH_JWT_SECRET` | Yes | Shared HS256 signing/verification secret, at least 32 bytes. Configure the identical value on every protected API. |
| `AUTH_ADMIN_EMAIL` | Yes | Single administrator email; comparison is trimmed and case-insensitive. |
| `AUTH_ADMIN_PASSWORD_HASH` | Yes | PBKDF2-SHA256 hash generated by `python hash_password.py`. |
| `AUTH_ADMIN_NAME` | No | Display name; defaults to `Administrator`. |
| `CORS_ORIGINS` | No | Comma-separated allowed browser origins; default is `http://localhost:3000,http://localhost:3003`. Set exact deployed frontend origins. |

Illustrative values only:

```dotenv
AUTH_JWT_SECRET=replace-with-private-random-value-at-least-32-bytes
AUTH_ADMIN_EMAIL=admin@example.com
AUTH_ADMIN_NAME=Administrator
AUTH_ADMIN_PASSWORD_HASH=paste-generated-pbkdf2-hash-here
CORS_ORIGINS=http://localhost:3000
```

## Run locally

From this directory, install requirements and configure `.env`, then:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8002
```

Suggested base URL: `http://localhost:8002`. FastAPI interactive docs are at `/docs` while running.

Run tests:

```bash
python -m unittest
```

## Docker

From this directory, create a runtime `.env`, then:

```bash
docker build -t ai-admin-auth .
docker run --rm --name ai-admin-auth --env-file .env -p 8002:8000 ai-admin-auth
```

The image listens on port 8000 internally and runs as an unprivileged user. Do not bake `.env` into the image; use a production secret manager and configure `CORS_ORIGINS` for the dashboard's real origin.

## API

- `POST /auth/login` — body `{"email":"admin@example.com","password":"..."}`; returns `access_token`, `token_type`, and `user`.
- `GET /auth/me` — requires `Authorization: Bearer <token>`.
- `GET /healthz` — unauthenticated liveness response.
